# FoxBait BLE console (moved)

**Moved 2026-11-11 to https://thylation-research.github.io/foxbait-ble/ (repo thylation-research/foxbait-ble).** This repo now only redirects; `legacy.html` is the last page here, kept so a phone can still read settings it saved under this address.

Phone pages for the FoxBait board over Bluetooth (Nordic UART service): `index.html` is the board's own control page (built by `tools/ble_console/build_ble_ui.py`), `console.html` a plain command console.
On an iPhone open https://pitapun.github.io/foxbait-ble/ in the **Bluefy** app
(Safari has no Web Bluetooth). Press the button on the board first, then Connect.

Source of truth: `firmware/foxbait/tools/ble_console/index.html` in fox_bait_station.
